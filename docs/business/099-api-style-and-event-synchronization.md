# سبک ارتباط API و همگام‌سازی محصولات فانل

- وضعیت: تصمیم معماری تأییدشده برای ادامه‌ی طراحی
- شماره‌ی تصمیم: ۰۹۹
- تاریخ ثبت: ۲۰۲۶-۱۰-۱۶
- دامنه: ارتباط CRM با محصولات فانل و سامانه‌های مشتری

## تصمیم

REST/JSON سبک اصلی API برای درخواست و پاسخ مستقیم میان CRM و محصولات متصل باشد. رویدادهای تغییر برای همگام‌سازی فوری از مسیر Apache Kafka منتشر شوند. GraphQL و gRPC در استاندارد اصلی این محصول قرار نمی‌گیرند و فقط در صورت نیاز مشخص جداگانه بررسی می‌شوند.

## اصول

- APIهای REST/JSON از قراردادهای نسخه‌دار تصمیم ۰۹۸ پیروی کنند.
- تغییرهای پذیرفته‌شده برای انتشار رویداد منتظر پردازش دسته‌ای نمانند.
- مصرف‌کنندگان Kafka مستقل پردازش کنند و نتیجه‌ی اجرای اقدام‌های مجاز را گزارش دهند.
- REST/JSON برای تبادل مستقیم درخواست و پاسخ است؛ Kafka برای انتشار رویداد و همگام‌سازی.
- جزئیات پیاده‌سازی و هدف عددی تأخیر در طراحی فنی و آزمون بار تعیین شود.

## معیار پذیرش

- مصرف‌کننده بتواند از API نسخه‌دار برای درخواست مستقیم استفاده کند و پاسخ روشن بگیرد.
- تغییر پذیرفته‌شده بدون انتظار برای یک چرخه‌ی دسته‌ای به جریان رویداد منتشر شود.
- اختلال یا تأخیر مصرف‌کننده قابل‌مشاهده باشد و رویداد برای ادامه‌ی پردازش حفظ شود.
- انتشار هم‌زمان یک تغییر از API و رویداد باعث ثبت یا اجرای تکراری نشود.
- همگام‌سازی رویدادها با مجوزهای فضای کاری و منشأ داده سازگار بماند.
