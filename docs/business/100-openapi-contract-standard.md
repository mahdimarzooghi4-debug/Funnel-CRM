# استاندارد توصیف قرارداد APIهای REST

- وضعیت: تصمیم معماری تأییدشده برای ادامه‌ی طراحی
- شماره‌ی تصمیم: ۱۰۰
- تاریخ ثبت: ۲۰۲۶-۱۰-۱۶
- دامنه: توصیف و اعتبارسنجی قراردادهای REST/JSON

## تصمیم

قراردادهای REST/JSON CRM و محصولات متصل با استاندارد OpenAPI توصیف شوند. قرارداد قابل‌خواندن برای انسان و ماشین باشد و مبنای مستندسازی و بررسی سازگاری API قرار گیرد. انتخاب نسخه‌ی دقیق OpenAPI و ابزارهای اعتبارسنجی به طراحی فنی موکول می‌شود.

## اصول

- قرارداد API مرجع رفتار و ساختار درخواست‌ها و پاسخ‌ها باشد.
- تغییر قرارداد با تصمیم ۰۹۸ درباره‌ی نسخه‌بندی و سازگاری هماهنگ باشد.
- قراردادها پیش از انتشار بررسی و از نظر ناسازگاری قابل‌آزمون باشند.
- انتخاب ابزار تولید مستندات، کد یا آزمون در این تصمیم انجام نمی‌شود.

## معیار پذیرش

- هر API منتشرشده قرارداد OpenAPI قابل‌دسترسی داشته باشد.
- قرارداد شامل مسیرها، ورودی‌ها، پاسخ‌ها، خطاها و الزامات دسترسی باشد.
- تغییر ناسازگار در بازبینی قرارداد شناسایی شود.
- مستندات API از قرارداد نسخه‌دار قابل تولید یا اعتبارسنجی باشند.
