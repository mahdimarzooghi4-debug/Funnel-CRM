# Sprint 81: sales close-date worklist

Add a tenant- and organization-scoped read-only worklist for sales opportunities. Classify expected close dates against a caller-selected reference date and horizon as overdue, due soon, later, or unscheduled. Return category counts for the filtered scope, stable priority ordering, pagination, and an audit event for each view.

The worklist reports only configured expected close dates. It does not infer follow-up urgency, win probability, or sales outcomes.
