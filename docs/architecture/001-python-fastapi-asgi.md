# تصمیم فنی ۰۰۱: Python برای بک‌اند CRM فانل

- وضعیت: انتخاب‌شده برای بک‌اند و API
- تاریخ: 2026-10-14
- دامنه: زبان و چارچوب API؛ این سند کل پشته‌ی فناوری را نهایی نمی‌کند.

## تصمیم

بک‌اند CRM با **Python و FastAPI** ساخته شود و APIها روی **ASGI** اجرا شوند. ساختار کد به‌صورت برنامه‌ی ماژولار باشد تا قابلیت‌های CRM مرز روشن داشته باشند و محصولات مستقل فانل از طریق API و رویدادهای نسخه‌دار متصل شوند.

## دلیل انتخاب

بخش زیادی از درخواست‌های CRM منتظر پایگاه داده، سرویس‌های بیرونی یا سرویس هوش مصنوعی می‌مانند. مستند رسمی Python، `asyncio` را مناسب I/O شبکه معرفی می‌کند؛ FastAPI نیز اجرای درخواست‌های هم‌زمان در یک process را مستند کرده و برای استفاده از هسته‌های بیشتر، اجرای چند process را توضیح می‌دهد.

این توانایی به معنی تعداد ثابت یا تضمین‌شده‌ای از درخواست در ثانیه نیست. ظرفیت واقعی به مسیر درخواست، تعداد و زمان پرس‌وجوهای پایگاه داده، اندازه‌ی پاسخ، محدودیت اتصال‌ها و میزان کار CPU بستگی دارد. بنابراین انتخاب Python بر اساس قابلیت فنی انجام شده و هدف ظرفیت باید با بار واقعی سنجیده شود.

## قواعد اجرایی

- سرویس HTTP با FastAPI در محیط ASGI اجرا شود.
- مسیرهای پرترافیک تا حد امکان غیرمسدودکننده و async باشند؛ کد هم‌زمان‌ساز نباید روی event loop کار CPU سنگین انجام دهد.
- محاسبات CPUمحور، گزارش‌های سنگین و کارهای طولانی در worker یا گردش‌کار پس‌زمینه اجرا شوند.
- افزایش ظرفیت با چند process و افزودن نمونه‌های سرویس انجام شود؛ ظرفیت پایگاه داده و pool اتصال نیز هم‌زمان پایش شود.
- هر API محدودیت زمانی، ثبت خطا و شاخص‌های latency و throughput داشته باشد.
- پیش از عرضه، آزمون بار روی مسیرهای واقعی CRM انجام شود؛ شامل احراز هویت، محدودیت سازمانی، دسترسی، پرس‌وجوی پایگاه داده و ساخت پاسخ. معیارهای پذیرش شامل throughput هدف، p95/p99 زمان پاسخ، نرخ خطا، مصرف CPU/حافظه و فشار پایگاه داده باشد.
- پشتیبانی از ASGI به‌تنهایی جایگزین آزمون بار، طراحی query، کنترل pool اتصال و جداسازی کارهای سنگین نیست.

## انتخاب چارچوب در قیاس با Django REST Framework

Django نیز در حالت ASGI پشتیبانی async دارد. با این حال، صفحه‌ی رسمی Django REST Framework، پشتیبانی async برای viewها و serializerها را در فهرست بسته‌های جانبی (از جمله `adrf`) آورده است. برای نیاز فعلی به APIهای async، FastAPI انتخاب مستقیم‌تری است. این انتخاب به معنی رد Django برای همه‌ی کاربردها نیست؛ فقط چارچوب API بک‌اند CRM را مشخص می‌کند.
