# Sprint 211: Campaign signal follow-up tasks

Managers can convert a current campaign target signal into an assigned CRM work item. The endpoint recomputes the selected metric from tenant- and organization-scoped target and measurement data before creating the task, so stale or resolved signals cannot create follow-up work. Commerce-based signals also require commerce-event access.

Created work items remain linked to the campaign and include signal evidence and coverage in their description and audit record. No campaign setting changes automatically.
