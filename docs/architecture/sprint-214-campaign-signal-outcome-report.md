# Sprint 214: Campaign signal outcome report

Campaign performance analytics now includes a paginated report of manager decisions recorded on campaign signal follow-up tasks. Managers can filter by date, organization, campaign, decision, or metric and review the decision counts alongside the actual metric snapshots captured at the time of review.

Results require both campaign-view and work-item-view access to the organization scope. The report is descriptive and does not claim that a recorded decision caused subsequent metric movement.
