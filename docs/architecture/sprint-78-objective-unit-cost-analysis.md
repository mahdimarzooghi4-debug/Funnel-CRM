# Sprint 78: objective-level unit cost analysis

Add objective-level cost per recorded lead and conversion. The calculation sums spend and outcomes only for campaigns with a single recorded spend currency and an observed metric; each metric uses its own contributing campaign coverage. Metrics that are missing or have a zero aggregate denominator remain unavailable. Multi-currency campaign spend is not assigned to an arbitrary currency.

This is a descriptive ratio of recorded values. It is not ROI, attribution, or a causal estimate. The table is included in CSV exports.
