# Sprint 54: portfolio target coverage and metric context

Campaign target evaluation now reports compatible observed-day coverage, and the portfolio report returns the shared KPI definitions used by its outcome totals.

- Each target result includes observed days, calendar days in the target period, and recorded-day coverage percentage.
- The portfolio response identifies the matching metric definition once at report level, including aliases for spend and measurement-reported ROAS.
- Group-level met/not-met/no-data counts remain unchanged. Coverage describes available observations; it does not infer zero activity or reporting completeness.
- Existing organization scope and campaign-view permission checks remain in force.
