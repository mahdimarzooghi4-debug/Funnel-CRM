# Sprint 96: marketing learning portfolio

Adds a paginated portfolio view for manager-authored marketing learning reviews. The report connects each assessment and corrective action to its baseline campaign target period and, when recorded, the follow-up target period. It supports organization scope, baseline-period overlap filters, planned/evaluated status filtering, and status counts for the selected scope and period. Portfolio access is audit logged.

The view surfaces recorded observations and manager-written lessons. It does not compare unlike targets as if they were equivalent, infer causality, or generate recommendations. Existing review detail remains the source for metric-level baseline and follow-up evaluations.

Integration coverage verifies the portfolio before and after a review is evaluated, including period linkage, status totals, and audit evidence.
