# Sprint 217: Consent-aware segment reach

Segment managers can request an aggregate reach estimate for a purpose and communication channel. The report counts audience members, profiles with contact points, verified contact points, granted consent, withdrawn consent, and the final eligible audience.

Eligibility requires both a verified contact point on the selected channel and the latest explicit consent decision to be granted for the requested purpose. Missing consent is ineligible. The response includes counts only and does not expose encrypted contact-point values. Access requires profile, contact-point, segment, and communication-consent visibility in the organization scope.
